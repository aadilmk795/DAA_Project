# Binary Search

Simple C++ implementation of Binary Search algorithm.

### What it does
Searches for a target element in a sorted array by repeatedly dividing the search space in half.

### How it works
- Starts with the middle element
- If the middle element is the target, return its position
- If the target is smaller, search the left half
- If the target is larger, search the right half
- Continues until the element is found or the search space is empty

### How to run
1. Compile the code: `g++ Bsearch.cpp -o binary_search`
2. Run the program: `./binary_search`
