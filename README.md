# DAA_Project

This repository contains simple C++ implementations of basic algorithms from Design and Analysis of Algorithms (DAA).

## Programs Included

- **Binary Search** (`Bsearch.cpp`)
- **Insertion Sort** (`Insertion sort.cpp`)
- **Selection Sort** (`selection.cpp`)

Each program has its own README explaining how it works and how to run it.

## About
These are college practice programs. I understand the logic of these algorithms and can explain them.
