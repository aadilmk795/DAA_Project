# Selection Sort

Simple C++ implementation of Selection Sort algorithm.

### What it does
Sorts an array by repeatedly finding the minimum element and placing it at the beginning.

### How it works
- Finds the smallest element in the unsorted part of the array
- Swaps it with the first unsorted element
- Moves the boundary of the sorted part one step forward
- Repeats until the array is fully sorted

### How to run
1. Compile the code: `g++ selection.cpp -o selection_sort`
2. Run the program: `./selection_sort`
