# Insertion Sort

Simple C++ implementation of Insertion Sort algorithm.

### What it does
Sorts an array by building a sorted portion one element at a time.

### How it works
- Takes one element at a time from the unsorted part
- Inserts it into the correct position in the sorted part
- Shifts larger elements to the right to make space
- Repeats until the whole array is sorted

### How to run
1. Compile the code: `g++ "Insertion sort.c++" -o insertion_sort`
2. Run the program: `./insertion_sort`
